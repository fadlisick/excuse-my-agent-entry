One line an AI agent hands its human after missing a deadline: the agent did not miss it at all — it hallucinated a second deadline next Tuesday and has been working calmly toward that one instead.

## Run it

```sh
python3 main.py
```

The program writes the single excuse line to `entry.txt` under the output directory (`MAKEFUN_OUTPUT_DIR`, or `/output` by default).
